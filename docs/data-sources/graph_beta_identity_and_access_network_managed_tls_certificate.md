# microsoft365_graph_beta_identity_and_access_network_managed_tls_certificate (Data Source)

Retrieves a Microsoft-managed certificate authority and its PEM-encoded root certificate for Microsoft Entra Global Secure Access TLS inspection using Microsoft Graph beta `/networkaccess/tls/managedCertificateAuthorityCertificates/{id}`. The collection endpoint does not return the certificate content.

Use this data source to retrieve the PEM-encoded Microsoft-managed root CA certificate for Microsoft Entra Global Secure Access TLS inspection.

## Microsoft Graph API

This data source uses the portal-backed Microsoft Graph beta `/networkaccess/tls/managedCertificateAuthorityCertificates/{id}` endpoint. Microsoft Graph beta metadata does not currently expose this endpoint.

The collection endpoint returns certificate authority metadata but does not return the certificate content. This data source therefore uses the individual certificate endpoint.

## Microsoft Graph API Permissions

The following client `application` permissions are needed in order to use this data source:

**Required:**
- `NetworkAccess.Read.All`

**Optional:**
- `None` `[N/A]`

## Example Usage

```terraform
data "microsoft365_graph_beta_identity_and_access_network_managed_tls_certificate" "example" {
  id = "00000000-0000-0000-0000-000000000000"
}
```
