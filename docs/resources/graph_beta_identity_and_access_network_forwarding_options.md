# microsoft365_graph_beta_identity_and_access_network_forwarding_options (Resource)

Manages Microsoft Entra Global Secure Access DNS forwarding using Microsoft Graph beta `/networkAccess/settings/forwardingOptions`. Initial apply updates the existing tenant-wide settings; destroy removes Terraform state only and leaves the remote settings unchanged. Manage one instance per tenant. Updates preserve unmanaged properties.

## Related Resources

This resource controls the DNS forwarding strategy for Microsoft 365 traffic. `skip_dns_lookup_state = "enabled"` skips the service-side DNS lookup; it does not enable Internet Access. Restore the desired value before destroy if necessary, because destroy leaves the remote setting unchanged.

Manage proxy enablement and session affinity with [network_explicit_forward_proxy](graph_beta_identity_and_access_network_explicit_forward_proxy.md), and hosted PAC files with [network_proxy_auto_configuration](graph_beta_identity_and_access_network_proxy_auto_configuration.md). Neither requires a dependency on this DNS setting.

## Microsoft Graph API Permissions

- Read / Write (application): `NetworkAccess.ReadWrite.All`, verified in live testing.

The Graph references above currently list delegated `NetworkAccessPolicy.Read.All` for GET and `NetworkAccessPolicy.ReadWrite.All` for PATCH, and mark application access unsupported. Verify application access in your tenant.

## Example Usage

```terraform
# Use the client-resolved destination IP for Microsoft 365 traffic.
# This DNS setting is independent of EFP enablement and PAC hosting.
# Initial apply updates existing settings; destroy only removes state.
resource "microsoft365_graph_beta_identity_and_access_network_forwarding_options" "example" {
  skip_dns_lookup_state = "enabled"
}
```
