# microsoft365_graph_beta_identity_and_access_network_threat_intelligence_policy (Resource)

Manages Microsoft Entra Global Secure Access threat intelligence policies using the Microsoft Graph beta `/networkaccess/threatIntelligencePolicies` endpoint. Rules are managed separately with `microsoft365_graph_beta_identity_and_access_network_threat_intelligence_policy_rule`. Microsoft automatically creates a default blocking rule. It cannot be deleted or disabled independently and is managed only through the policy lifecycle. Deleting a policy also deletes its rules. Creating a policy does not apply it to traffic. Traffic enforcement requires a filtering profile link and its applicable assignment. See [Configure threat intelligence](https://learn.microsoft.com/en-us/entra/global-secure-access/how-to-configure-threat-intelligence).

## Example Usage

```terraform
resource "microsoft365_graph_beta_identity_and_access_network_threat_intelligence_policy" "example" {
  name           = "Example threat intelligence policy"
  description    = "Initial description"
  default_action = "allow"
}
```
