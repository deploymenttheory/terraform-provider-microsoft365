# microsoft365_graph_beta_identity_and_access_network_mcp_policy (Resource)

Manages Microsoft Entra Global Secure Access MCP policy containers using the portal-backed Microsoft Graph beta `/networkaccess/mcpPolicies` endpoint. Rules have independent lifecycles in `microsoft365_graph_beta_identity_and_access_network_mcp_policy_rule`. Deleting the policy cascades to all its rules, including rules managed elsewhere. Creating this resource does not assign it to traffic. This API is not currently described in Graph beta metadata. All CRUD operation timeouts default to 3 minutes.

## API Support

This resource uses the portal-backed Microsoft Graph beta MCP policy API, which is not represented in the generated Graph SDK used by this provider. Endpoint availability depends on the tenant's Global Secure Access feature and licensing. API persistence was tested with disposable, unassigned policies; traffic evaluation was not tested.

## Microsoft Graph API Permissions

For application authentication, configure `NetworkAccess.ReadWrite.All` with administrator consent for CRUD operations. Read-only operations require `NetworkAccess.Read.All` or `NetworkAccess.ReadWrite.All`. Delegated authentication also depends on the signed-in user's role and the client application's granted scopes.

## Example Usage

```terraform
resource "microsoft365_graph_beta_identity_and_access_network_mcp_policy" "test" {
```
