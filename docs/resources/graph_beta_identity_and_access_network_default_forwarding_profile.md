# microsoft365_graph_beta_identity_and_access_network_default_forwarding_profile (Resource)

Manages a built-in Microsoft Entra Global Secure Access traffic forwarding profile (traffic forwarding profile v2) using Microsoft Graph beta `/networkaccess/forwardingProfiles`. The profile is selected by `traffic_forwarding_type`. Initial apply updates the existing default profile; destroy removes Terraform state only and leaves the remote profile unchanged. Manage one instance per traffic type per tenant. Use `microsoft365_graph_beta_identity_and_access_network_forwarding_profile` for custom profiles. Policy links and remote network associations are not managed by this resource.

## Prerequisites

The tenant must be onboarded to Global Secure Access and use traffic forwarding profiles v2. Switching to v2 cannot be undone.

## Considerations

- The default profile ID differs per tenant, so the profile is selected by `traffic_forwarding_type`.
- `name`, `description` and `priority` are read-only on default profiles.
- Only the attributes you configure are sent. Omitted attributes keep their current values.
- `assignment_rules` replaces all assignments of the profile.
- `local_network_settings` ([home network support](https://learn.microsoft.com/en-us/entra/global-secure-access/how-to-configure-home-network-support), preview) applies to the `private` profile only.
- Destroy does not disable, reset or delete the profile. Disable it explicitly with `state = "disabled"` before removing the resource if needed.

## Microsoft Graph API Permissions

- Read / Write (application): `NetworkAccess.ReadWrite.All`, verified in live testing.

The v2 profile properties are not documented in the Microsoft Graph reference. The request shapes follow the Microsoft Entra admin center.

## Example Usage

```terraform
# Enable the built-in Internet Access profile for one group on Windows and macOS.
resource "microsoft365_graph_beta_identity_and_access_network_default_forwarding_profile" "internet" {
  traffic_forwarding_type = "internet"
  state                   = "enabled"
  client_fallback_action  = "bypass"

  assignment_rules = {
    membership = "enumerated"
    group_ids  = ["00000000-0000-0000-0000-000000000001"]
    platforms  = ["windows", "macOS"]
  }
}

# Turn on home network support for everyone assigned to the default Private
# Access profile, leaving its assignments unchanged.
resource "microsoft365_graph_beta_identity_and_access_network_default_forwarding_profile" "private" {
  traffic_forwarding_type = "private"
  state                   = "enabled"

  local_network_settings = {
    allow_local_subnet_bypass = true
  }
}
```

- `state` (String) Whether the profile is enabled. Values: `enabled`, `disabled`.
- `traffic_forwarding_type` (String) Traffic type of the built-in profile to manage. Values: `private`, `internet`, `m365`. Changing it moves management to another default profile.
