# microsoft365_graph_beta_applications_on_premises_connector_group_member (Resource)

Assigns an installed Microsoft Entra private network (Application Proxy) connector to a connector group using the Microsoft Graph beta `/onPremisesPublishingProfiles/applicationProxy/connectors/{id}/memberOf/$ref` endpoint. A connector always belongs to exactly one connector group, so creating or updating this resource moves the connector into `connector_group_id`. Deleting this resource moves the connector back to the tenant's default connector group.

## Example Usage

### Minimal

```terraform
# Assign an installed private network connector to an existing connector group.
resource "microsoft365_graph_beta_applications_on_premises_connector_group_member" "minimal" {
  connector_id       = "00000000-0000-0000-0000-000000000000"
  connector_group_id = "11111111-1111-1111-1111-111111111111"
}
```

### Maximal

```terraform
# Create a connector group and move an installed private network connector into it.
resource "microsoft365_graph_beta_applications_on_premises_connector_group" "europe" {
  name   = "Europe connectors"
  region = "eur"
}

resource "microsoft365_graph_beta_applications_on_premises_connector_group_member" "maximal" {
  connector_id       = "00000000-0000-0000-0000-000000000000"
  connector_group_id = microsoft365_graph_beta_applications_on_premises_connector_group.europe.id

  timeouts = {
    create = "180s"
    read   = "180s"
    update = "180s"
    delete = "180s"
  }
}
```

## Important Notes

### Prerequisites

- The connector must already be installed and registered in the tenant. Microsoft Graph cannot create connectors; install the private network connector agent on a server first.

### One Group Per Connector

- A connector always belongs to exactly one connector group. Creating this resource moves the connector out of its current group into `connector_group_id`.
- The resource ID is the connector ID. Manage each connector with a single instance of this resource.
- Changing `connector_group_id` moves the connector to the new group in place. Changing `connector_id` replaces the resource.
- Moving a connector changes which published applications it serves. Applications assigned to the old group lose this connector.

### Drift

- If the connector is moved to another group outside Terraform, the next plan shows `connector_group_id` changing back to the configured group.

### Deletion

- Microsoft Learn documents no call to remove a connector from a group, and a connector cannot be left without one. Deleting this resource moves the connector back to the tenant's default connector group.
- Terraform refreshes before destroying, so if the connector was moved to another group outside Terraform, deletion moves it from that group back to the default group.
- If the managed group is the default group, deletion only removes the resource from state. If the connector's current group no longer matches state (for example with `-refresh=false`), deletion also only removes the resource from state and does not move the connector.

### Eventual Consistency

- After a move, Microsoft Graph can briefly report the previous group. The provider retries the read until the new group is returned.
