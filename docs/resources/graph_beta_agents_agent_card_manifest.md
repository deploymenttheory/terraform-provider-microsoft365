# microsoft365_graph_beta_agents_agent_card_manifest (Resource)

Manages an existing Microsoft Graph beta agent card manifest using GET and PATCH /agentRegistry/agentCardManifests/{id}. Create adopts and patches the existing manifest; it does not create an agent instance or a manifest. Destroy removes Terraform state only because Graph documents no standalone manifest DELETE operation. Create the manifest through an agent instance first. Unconfigured optional properties retain remote values; explicitly empty collections are sent as empty arrays. Do not configure the same manifest fields in another Terraform resource. Security dictionaries and extension parameters use JSON to preserve their extensible shape.

## Microsoft Documentation

- [Agent card manifest](https://learn.microsoft.com/en-us/graph/api/resources/agentcardmanifest?view=graph-rest-beta)
- [Get manifest](https://learn.microsoft.com/en-us/graph/api/agentcardmanifest-get?view=graph-rest-beta)
- [Update manifest](https://learn.microsoft.com/en-us/graph/api/agentcardmanifest-update?view=graph-rest-beta)
- [Get instance manifest](https://learn.microsoft.com/en-us/graph/api/agentinstance-list-agentcardmanifest?view=graph-rest-beta)

## Microsoft Graph API Permissions

Application permission: AgentCardManifest.ReadWrite.All or AgentCardManifest.ReadWrite.ManagedBy (and matching read access).

## Example Usage

```terraform
# Provision the manifest through an agent instance first.
# This resource adopts and updates it. Destroy only removes Terraform state.
resource "microsoft365_graph_beta_agents_agent_card_manifest" "example" {
  agent_card_manifest_id = "existing-manifest-id"
  display_name           = "Employee assistant"
  description            = "Answers employee questions"
  protocol_version       = "1.0"
  version                = "1.0.0"
  default_input_modes    = ["text"]
  default_output_modes   = ["text"]
  agent_provider = {
    organization = "Contoso"
    url          = "https://contoso.com"
  }
  capabilities = {
    streaming = true
  }
}
```
