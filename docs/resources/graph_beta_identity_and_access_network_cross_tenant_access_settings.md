# microsoft365_graph_beta_identity_and_access_network_cross_tenant_access_settings (Resource)

Manages Microsoft Entra Global Secure Access universal tenant restrictions using the Microsoft Graph beta `/networkAccess/settings/crossTenantAccess` endpoint. This is separate from `/policies/crossTenantAccessPolicy`.

This is a tenant-wide singleton with documented GET and PATCH operations only. Initial apply updates the existing settings using PATCH. Destroy removes the resource from Terraform state only; it does not disable, delete, or reset the remote settings. Manage only one instance per tenant across all Terraform states.

Enabling packet tagging applies configured tenant restrictions to affected traffic and can block access to external tenants. Configure and review the tenant restrictions policy before enabling this setting.

## Microsoft Graph API Permissions

For application authentication:

- Read: `NetworkAccess.Read.All` or `NetworkAccess.ReadWrite.All`.
- Write: `NetworkAccess.ReadWrite.All`.

This beta API is documented for the Global service only. A tenant with Global Secure Access available is required.

## Lifecycle

- Initial apply and status updates PATCH the existing singleton.
- Read and import retrieve the singleton with GET.
- Destroy removes Terraform state only and leaves all remote settings unchanged, including enabled tagging. Apply `network_packet_tagging_status = "disabled"` first if you intend to disable tagging.
- Manage only one instance per tenant, including across workspaces and state files.
- This resource does not configure the separate `/policies/crossTenantAccessPolicy` policy. Review that policy before enabling tagging, because external-tenant access can be blocked.
- Only `networkPacketTaggingStatus` is sent in updates (plus the SDK type discriminator). Other service properties are not managed.

## Example Usage

```terraform
# One instance per tenant. Initial apply updates the existing singleton.
# Review tenant restrictions policies and the access impact before enabling tagging.
resource "microsoft365_graph_beta_identity_and_access_network_cross_tenant_access_settings" "example" {
  network_packet_tagging_status = "disabled"
}

# Destroy only releases Terraform management; it does not change these settings.
```
