# microsoft365_graph_beta_identity_and_access_security_defaults_enforcement_policy (Resource)

Manages the tenant-wide Microsoft Entra ID security defaults enforcement policy using the Microsoft Graph beta `/policies/identitySecurityDefaultsEnforcementPolicy` endpoint. Security defaults turn on a baseline of identity protections for every user in the tenant, including mandatory MFA registration.

This is a **singleton resource**: one policy exists per tenant. `create` adopts the existing policy and `create`/`update` apply `is_enabled` with PATCH. On `destroy`, Terraform only removes the resource from state and leaves security defaults as they are. Manage only one instance per tenant across all Terraform states.

Microsoft Entra ID rejects enabling security defaults while Conditional Access policies are enabled in the tenant.

## Example Usage

### Minimal

```terraform
# Keep Microsoft Entra ID security defaults disabled, for example because the tenant
# is protected with Conditional Access policies instead.
resource "microsoft365_graph_beta_identity_and_access_security_defaults_enforcement_policy" "example" {
  is_enabled = false
}
```

### Maximal

```terraform
# Enable Microsoft Entra ID security defaults for the tenant.
#
# WARNING: this enforces security defaults, including MFA registration, for every user in
# the tenant. Graph rejects enabling security defaults while Conditional Access policies
# are enabled, so disable those policies first or keep is_enabled = false.
resource "microsoft365_graph_beta_identity_and_access_security_defaults_enforcement_policy" "example" {
  is_enabled = true

  timeouts = {
    create = "3m"
    read   = "3m"
    update = "3m"
    delete = "3m"
  }
}
```

## Important Notes

### Singleton Resource
- One security defaults enforcement policy exists per tenant. It cannot be created or deleted.
- `create` adopts the existing policy and applies `is_enabled` with `PATCH`.
- `destroy` only removes the resource from Terraform state; security defaults keep their current setting. Destroying the resource never enables or disables security defaults.
- Manage only one instance per tenant across all Terraform states.

### Impact of Enabling Security Defaults
- `is_enabled = true` enforces security defaults for every user in the tenant, including mandatory MFA registration, MFA for administrators and blocking legacy authentication.
- Review the impact on all users and service accounts before enabling security defaults.

### Conditional Access
- Security defaults and Conditional Access are mutually exclusive. Microsoft Entra ID rejects enabling security defaults while Conditional Access policies are enabled in the tenant.
- When Graph rejects the request, the provider shows Graph's error together with an explanation. Disable or delete the enabled Conditional Access policies first, or keep `is_enabled = false`.

### Read-Only Attributes
- `display_name` and `description` are set by Microsoft Entra ID and are never sent to Graph.
