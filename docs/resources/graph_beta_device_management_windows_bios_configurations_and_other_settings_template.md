# microsoft365_graph_beta_device_management_windows_bios_configurations_and_other_settings_template (Resource)

Manages the Intune 'BIOS configuration and other settings' template using the `/deviceManagement/hardwareConfigurations` endpoint. This template applies an OEM generated hardware/BIOS configuration file (for example a Dell Command | Configure `.cctk` package) to enrolled Windows 10/11 Microsoft Entra joined devices, allowing administrators to remotely control device hardware properties such as Secure Boot or TPM state. Dell is the only OEM supported by the service at this time.

## Example Usage

```terraform
// Example: Intune "BIOS configuration and other settings" template
//
// The configuration file is produced by the OEM's own tooling (for Dell, the
// Dell Command | Configure "multiplatform package" export) and uploaded to Intune
// base64 encoded. Use Terraform's filebase64() function to read it from disk.

resource "microsoft365_graph_beta_device_management_windows_bios_configurations_and_other_settings_template" "example" {
  display_name = "Example BIOS configuration"
  description  = "Secure Boot and TPM baseline for Dell workstations"

  file_name                  = "dell-bios-baseline.cctk"
  configuration_file_content = filebase64("${path.module}/dell-bios-baseline.cctk")

  # Optional: the service infers this from file_name when omitted.
  hardware_configuration_format = "dell"

  # Leave false so Intune generates and manages a unique BIOS password per device.
  per_device_password_disabled = false

  role_scope_tag_ids = ["0"]

  # Optional: assignments block. Only group inclusion and exclusion targets are
  # supported; included groups may additionally be narrowed by an assignment filter.
  assignments = [
    # Included group, narrowed by an assignment filter
    {
      type        = "groupAssignmentTarget"
      group_id    = "00000000-0000-0000-0000-000000000000"
      filter_id   = "11111111-1111-1111-1111-111111111111"
      filter_type = "include"
    },
    # Included group, no filter
    {
      type     = "groupAssignmentTarget"
      group_id = "22222222-2222-2222-2222-222222222222"
    },
    # Excluded group
    {
      type     = "exclusionGroupAssignmentTarget"
      group_id = "33333333-3333-3333-3333-333333333333"
    },
  ]

  timeouts = {
    create = "3m"
    read   = "3m"
    update = "3m"
    delete = "3m"
  }
}
```

## Important Notes

- **Dell Only**: Microsoft Intune currently supports this template for Dell devices only. The `hardware_configuration_format` attribute accepts `surface` and `surfaceDock`, but the service does not process those formats today.
- **Device Requirements**: Targeted devices must be Windows 10/11, Microsoft Entra joined (not hybrid joined or workplace joined), and have Dell Command | Monitor installed.
- **Configuration File**: The file is produced with the OEM's tooling — for Dell, an exported Dell Command | Configure "multiplatform package" (`.cctk`). It is uploaded base64 encoded, so use Terraform's `filebase64()` function rather than `file()`.
- **BIOS Passwords**: Do not set `SetupPwd` or `SysPwd` inside the configuration file. Leave `per_device_password_disabled` set to `false` and let Intune generate and manage a unique BIOS password for each device; those passwords are then retrievable from the Intune portal.
- **Sensitive Content**: `configuration_file_content` is marked sensitive because an OEM package can carry BIOS setup credentials. Its value is still stored in Terraform state, so protect your state backend accordingly.
- **Assignment Targets**: Only `groupAssignmentTarget` and `exclusionGroupAssignmentTarget` are supported, matching the Intune portal. There are no 'all devices' or 'all users' targets for this template.
- **Assignment Filters**: Included group assignments may be narrowed with an assignment filter. Set `filter_type` to `include` or `exclude` together with a `filter_id`; leave both at their defaults (`none` and the all-zero GUID) when no filter applies.
- **Reporting**: Per-device and per-user application status is reported by Intune but is not surfaced by this resource.
