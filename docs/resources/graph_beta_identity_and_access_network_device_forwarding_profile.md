# microsoft365_graph_beta_identity_and_access_network_device_forwarding_profile (Resource)

Manages a Microsoft Entra Global Secure Access pre-logon (device) forwarding profile using Microsoft Graph beta `/networkaccess/deviceForwardingProfiles`. Pre-logon profiles connect a device to Private Access before a user signs in to Windows. They support Private Access only and are assigned to devices or groups, not users. Destroy deletes the profile. Policy links are not managed by this resource.

## Prerequisites

The tenant must use traffic forwarding profiles v2. Pre-logon profiles are in preview and need a Global Secure Access client that supports pre-logon connectivity.

## Considerations

- Graph does not enforce unique priorities between pre-logon profiles. Profile names must be unique.
- The Microsoft Entra admin center offers only the `windows` platform; Graph also accepts the others.
- Assignment changes are eventually consistent. Create and update wait until three consecutive reads match the plan.

## Microsoft Graph API Permissions

- Read / Write (application): `NetworkAccess.ReadWrite.All`, verified in live testing.

`/networkaccess/deviceForwardingProfiles` is not documented in the Microsoft Graph reference. The request shapes follow the Microsoft Entra admin center.

## Example Usage

```terraform
# Pre-logon Private Access profile: connects devices to Private Access before a
# user signs in to Windows, for example to reach a domain controller.
resource "microsoft365_graph_beta_identity_and_access_network_device_forwarding_profile" "pre_logon" {
  name        = "Pre-logon - domain controllers"
  description = "Private Access before Windows sign-in"
  priority    = 180
  state       = "enabled"

  assignment_rules = {
    membership = "enumerated"
    group_ids  = ["00000000-0000-0000-0000-000000000001"]
    platforms  = ["windows"]
  }
}
```

## Schema

### Required

- `name` (String) Profile name.
- `priority` (Number) Profile priority, 101-200; lower wins. Graph accepts other values on update, but they would fail on re-create.
- `state` (String) Whether the profile is enabled. Values: `enabled`, `disabled`.

### Optional

- `assignment_rules` (Attributes) Group, device and platform assignments. Graph replaces assignments as a whole. Omitting it leaves the current assignments unchanged. (see [below for nested schema](#nestedatt--assignment_rules))
- `client_fallback_action` (String) What the client does with acquired traffic when it cannot reach Global Secure Access. Values: `bypass`, `block`. Graph defaults to `bypass`. Omitting it leaves the current value unchanged.
- `description` (String) Profile description.
- `local_network_settings` (Attributes) Home network support (preview). Supported only for `private` profiles. Omitting it leaves the current value unchanged. (see [below for nested schema](#nestedatt--local_network_settings))
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))

### Read-Only

- `id` (String) Forwarding profile ID.
- `traffic_forwarding_type` (String) Traffic type. Always `private`; Graph supports pre-logon profiles for Private Access only.
- `version` (String) Profile version.

### Nested Schema for `assignment_rules`

Required:

- `membership` (String) `all` assigns all devices, `enumerated` assigns the listed IDs, `none` assigns nothing.
- `platforms` (Set of String) Device platforms the profile applies to. Values: `windows`, `macOS`, `android`, `iOS`. At least one is required.

Optional:

- `device_ids` (Set of String) Microsoft Entra device object IDs, in lowercase. Allowed only when `membership` is `enumerated`.
- `group_ids` (Set of String) Microsoft Entra security group object IDs, in lowercase. Allowed only when `membership` is `enumerated`.
- `user_ids` (Set of String) Not supported on pre-logon profiles; Graph rejects user assignments.
