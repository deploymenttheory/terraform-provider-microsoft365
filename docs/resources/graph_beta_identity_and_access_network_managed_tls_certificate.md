# microsoft365_graph_beta_identity_and_access_network_managed_tls_certificate (Resource)

Manages a Microsoft-managed certificate authority for Microsoft Entra Global Secure Access TLS inspection using the portal-backed Microsoft Graph beta `/networkaccess/tls/managedCertificateAuthorityCertificates` endpoint.

This resource manages the Microsoft-managed root certificate authority used by Microsoft Entra Global Secure Access TLS inspection.

## Microsoft Graph API

This resource uses the portal-backed Microsoft Graph beta `/networkaccess/tls/managedCertificateAuthorityCertificates` endpoint. Microsoft Graph beta metadata does not currently expose this endpoint.

Creation uses `POST /beta/networkaccess/tls/managedCertificateAuthorityCertificates`. When `enabled` is `true`, the provider subsequently sends `PATCH /beta/networkaccess/tls/managedCertificateAuthorityCertificates/{id}` with `status = "enabled"` and waits for the observed lifecycle status to become `active`.

## Behavior Notes

- The create request follows the Entra portal and does not include `status` in the POST payload.
- A newly created certificate is disabled by default. The provider does not send an immediate `status = "disabled"` PATCH because Microsoft Graph rejects that command while the certificate is provisioning.
- `enabled` represents the desired Terraform state, while `status` exposes the lifecycle state reported by Microsoft Graph.
- The provider uses the individual certificate GET endpoint to populate the root CA certificate.

## Microsoft Graph API Permissions

The following client `application` permissions are needed in order to use this resource:

**Required:**
- `NetworkAccess.Read.All`
- `NetworkAccess.ReadWrite.All`

**Optional:**
- `None` `[N/A]`

## Example Usage

```terraform
resource "microsoft365_graph_beta_identity_and_access_network_managed_tls_certificate" "example" {
  # The remaining certificate subject and validity values use the same defaults
  # as the Microsoft Entra portal.
  enabled = true
}
```

## Schema

### Optional

- `common_name` (String) The common name (CN) of the Microsoft-managed root certificate authority.
- `enabled` (Boolean) Whether the certificate authority should be enabled for TLS inspection. Enabling sends `status = "enabled"` to Microsoft Graph and waits for the observed lifecycle status to become `active`. Disabling waits for `disabled`.
- `name` (String) The internal name of the certificate authority. When omitted, the provider generates a portal-compatible name in the form `M-TLSi-xxxxx`.
- `organization_name` (String) The organization name (O) of the Microsoft-managed root certificate authority.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))
- `validity_months` (Number) The root certificate validity period in months. The Entra portal uses `120` months.

### Read-Only

- `certificate` (String) The Microsoft-managed root CA certificate returned by Microsoft Graph.
- `created_date_time` (String) The date and time when the certificate authority was created.
- `id` (String) The unique identifier for the Microsoft-managed TLS certificate authority.
- `status` (String) The lifecycle status reported by Microsoft Graph, such as `unknownFutureValue` immediately after a disabled create, `creating`, `enrolling`, `disabled`, or `active`. This differs from the command value sent when enabling the certificate authority.
- `validity_end_date_time` (String) The end of the root certificate validity period.
- `validity_start_date_time` (String) The start of the root certificate validity period.
