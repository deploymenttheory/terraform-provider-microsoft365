# microsoft365_graph_beta_m365_admin_profile_card_property (Resource)

Manages a Microsoft 365 profile card property using the `/admin/people/profileCardProperties` endpoint. A profile card property surfaces a Microsoft Entra ID attribute (for example `CustomAttribute1` or `Alias`) on users' profile cards, optionally with a custom label and localized labels. Deleting the resource removes the profile card configuration only; the directory attribute and its values are not changed.

## Microsoft Graph API Permissions

The following client `application` permissions are needed in order to use this resource:

**Required:**
- `PeopleSettings.Read.All`
- `PeopleSettings.ReadWrite.All`

**Optional:**
- `None` `[N/A]`

Microsoft Learn currently lists only the delegated `PeopleSettings.ReadWrite.All` permission (with the People Administrator role) for create, update and delete. The application permission `PeopleSettings.ReadWrite.All` works with client credentials in practice and is what the provider's acceptance tests use.

## Example Usage

### Minimal

```terraform
# Minimal profile card property: show the Alias attribute on users' profile cards.
resource "microsoft365_graph_beta_m365_admin_profile_card_property" "alias" {
  directory_property_name = "Alias"
}
```

### Maximal

```terraform
# Maximal profile card property: show CustomAttribute1 with a custom label and localized labels.
resource "microsoft365_graph_beta_m365_admin_profile_card_property" "cost_center" {
  directory_property_name = "CustomAttribute1"
  is_visible              = true

  annotations = [
    {
      display_name = "Cost Center"
      localizations = [
        {
          language_tag = "de-DE"
          display_name = "Kostenstelle"
        },
        {
          language_tag = "nb-NO"
          display_name = "Kostnadssenter"
        }
      ]
    }
  ]

  timeouts = {
    create = "180s"
    read   = "180s"
    update = "180s"
    delete = "180s"
  }
}
```

## Important Notes

### Directory Property Name

- Each profile card property is identified by its `directory_property_name`, which is also the resource ID. Only one resource can manage a given attribute.
- Allowed values are `UserPrincipalName`, `Fax`, `StreetAddress`, `PostalCode`, `StateOrProvince`, `Alias` and `CustomAttribute1` to `CustomAttribute15`.
- Microsoft Graph stores the name exactly as sent and addresses it case-sensitively: `customAttribute1` and `CustomAttribute1` are different properties. Use the same casing as any existing property you import.
- Changing `directory_property_name` replaces the property.

### Labels

- `annotations` sets a custom label for the attribute, and `localizations` sets labels for other languages.
- Removing all `annotations` from configuration clears the labels in Microsoft Graph.

### Propagation to Clients

- Changes are returned by Microsoft Graph immediately, but can take up to 24 hours to appear on profile cards in Outlook, Teams and other Microsoft 365 apps.

### Deletion

- Deleting the resource removes the attribute and its labels from the profile card only. The Microsoft Entra attribute and its values are not changed.
