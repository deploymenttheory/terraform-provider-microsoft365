# microsoft365_graph_beta_identity_and_access_network_explicit_forward_proxy (Resource)

Manages Microsoft Entra Global Secure Access Explicit Forward Proxy using `/networkAccess/explicitForwardProxyConfig`. Initial apply updates the existing tenant-wide settings; destroy removes Terraform state only and leaves the remote settings unchanged. Manage one instance per tenant. Updates preserve Private Access, mTLS and other unmanaged properties.

## Related Resources

Enable `internet_access.is_enabled` before creating [hosted custom PAC files](graph_beta_identity_and_access_network_proxy_auto_configuration.md). That resource's example includes the required `depends_on`. [DNS forwarding options](graph_beta_identity_and_access_network_forwarding_options.md) are managed independently.

Restore the desired proxy settings before destroy if necessary; destroying this singleton resource leaves the remote configuration unchanged.

## Microsoft Documentation

- [Explicit Forward Proxy](https://learn.microsoft.com/en-us/entra/global-secure-access/concept-explicit-forward-proxy)

## Microsoft Graph API Permissions

- Read / Write (application): `NetworkAccess.ReadWrite.All`, verified in live testing.

A minimum read-only permission has not been verified.

## Example Usage

```terraform
# Configure TLS inspection, licensing and access policies before enabling EFP.
# Set is_enabled = true before creating hosted custom PAC files.
resource "microsoft365_graph_beta_identity_and_access_network_explicit_forward_proxy" "example" {
  internet_access = {
    is_enabled                            = false
    is_source_ip_session_affinity_enabled = true
    source_ip_session_affinity_options    = "useSessionId"
  }
}
```
