# microsoft365_graph_beta_identity_and_access_external_identities_policy (Resource)

Manages the tenant-wide Microsoft Entra external identities policy using the Microsoft Graph beta `/policies/externalIdentitiesPolicy` endpoint.

This is a **singleton resource** — one policy exists per tenant. Create and update use PATCH to configure the existing policy. On destroy, Terraform removes the resource from state only, leaving the policy unchanged. Manage only one instance per tenant across all Terraform states.

## Microsoft Documentation

- [externalIdentitiesPolicy resource type](https://learn.microsoft.com/en-us/graph/api/resources/externalidentitiespolicy?view=graph-rest-beta)

- [Update externalIdentitiesPolicy](https://learn.microsoft.com/en-us/graph/api/externalidentitiespolicy-update?view=graph-rest-beta&tabs=http)

## Important Notes

- **Singleton Resource**: Manage one instance per tenant across all Terraform states. The ID is always `externalIdentityPolicy`.
- **Create and Update Behavior**: Both operations use PATCH on `/policies/externalIdentitiesPolicy` to configure the existing policy, then GET to refresh state.
- **Destroy Behavior**: Only removes Terraform state. The policy and its settings remain in Microsoft Entra ID.
- **Boolean Settings**: Both policy Booleans are required. Specify `true` or `false` explicitly.
- **Read-Only Metadata**: `display_name` and `description` are computed from GET responses.
- **Privacy Profile Prerequisite**: Setting `allow_external_identities_to_leave = false` requires both `privacyContact` and `privacyStatementUrl` in the organization privacy profile. Microsoft Graph returns HTTP 400 when they are missing.
- **Reserved Property**: Microsoft documents `allowDeletedIdentitiesDataRemoval` as reserved for future use. Live beta API validation confirmed it can be updated and read back; no operational effect is documented.
