# microsoft365_graph_beta_identity_and_access_lifecycle_workflow_custom_task_extension (Resource)

Manages Microsoft Entra ID Governance lifecycle workflow custom task extensions using the `/identityGovernance/lifecycleWorkflows/customTaskExtensions` endpoint. A custom task extension lets a lifecycle workflow call an Azure Logic App. Graph does not check that the subscription, resource group or Logic App exist when the extension is created or updated.

## Microsoft Graph API Permissions

The following client `application` permissions are needed in order to use this resource:

**Required:**
- `LifecycleWorkflows-CustomExt.Read.All`
- `LifecycleWorkflows-CustomExt.ReadWrite.All`

**Optional:**
- `None` `[N/A]`

`LifecycleWorkflows.ReadWrite.All` also grants access. Lifecycle workflows require a Microsoft Entra ID Governance license in the tenant.

## Example Usage

### Minimal

```terraform
# Fire-and-forget custom task extension: the workflow calls the Logic App and continues without waiting.
resource "microsoft365_graph_beta_identity_and_access_lifecycle_workflow_custom_task_extension" "minimal" {
  display_name = "Notify HR system"

  endpoint_configuration = {
    subscription_id         = "00000000-0000-0000-0000-000000000000"
    resource_group_name     = "rg-identity-governance"
    logic_app_workflow_name = "la-notify-hr"
    # Required when the provider authenticates as an application (client credentials).
    url = "https://prod-00.westeurope.logic.azure.com:443/workflows/00000000000000000000000000000000/triggers/manual/paths/invoke?api-version=2016-10-01"
  }

  authentication_configuration = {
    type = "azureAdPopTokenAuthentication"
  }
}
```

### Maximal

```terraform
# Custom task extension that waits up to one hour for the Logic App to resume the workflow.
resource "microsoft365_graph_beta_identity_and_access_lifecycle_workflow_custom_task_extension" "maximal" {
  display_name = "Provision mailbox and wait for completion"
  description  = "Calls the provisioning Logic App and waits for it to report back"

  endpoint_configuration = {
    subscription_id         = "00000000-0000-0000-0000-000000000000"
    resource_group_name     = "rg-identity-governance"
    logic_app_workflow_name = "la-provision-mailbox"
    url                     = "https://prod-00.westeurope.logic.azure.com:443/workflows/00000000000000000000000000000000/triggers/manual/paths/invoke?api-version=2016-10-01"
  }

  authentication_configuration = {
    type        = "azureAdTokenAuthentication"
    resource_id = "11111111-1111-1111-1111-111111111111"
  }

  client_configuration = {
    maximum_retries         = 0
    timeout_in_milliseconds = 2000
  }

  callback_configuration = {
    timeout_duration = "PT1H"
    # Client ID of the Logic App's managed identity, allowed to resume the task.
    authorized_app_ids = ["22222222-2222-2222-2222-222222222222"]
  }

  timeouts = {
    create = "5m"
    read   = "5m"
    update = "5m"
    delete = "5m"
  }
}
```

## Important Notes

### Logic App

- Graph does not check that the subscription, resource group or Logic App in `endpoint_configuration` exist. A wrong value only fails when a workflow runs the task.
- When the provider authenticates as an application (client credentials), Graph requires `endpoint_configuration.url` and rejects the create with `Custom task extensions missing url` without it. Use the Logic App HTTP trigger URL without its query string signature, for example `https://prod-00.westeurope.logic.azure.com:443/workflows/<id>/triggers/manual/paths/invoke?api-version=2016-10-01`.
- The Logic App must be set up to accept calls from lifecycle workflows (its authorization policy and, for a callback, its managed identity). See the Microsoft documentation linked above.

### Reply mode and callback

- Without `callback_configuration` the workflow calls the Logic App and continues (`reply_mode = "none"`).
- With `callback_configuration` the workflow waits for the Logic App to resume the task (`reply_mode = "callback"`). `timeout_duration` must be between five minutes and three hours.
- Removing `callback_configuration` clears it in Microsoft Entra and switches `reply_mode` back to `none`.

### Authentication

- `azureAdPopTokenAuthentication` sends a Proof of Possession token and is the Microsoft Entra admin center default.
- `azureAdTokenAuthentication` sends a normal access token for the application in `resource_id`.

### Eventual Consistency

- For several seconds after an update, reads alternate between the new and the previous values. The provider retries the read until several reads in a row return the updated `last_modified_date_time`, so an update takes a few seconds longer than the PATCH itself.
