# microsoft365_graph_beta_identity_and_access_network_cloud_firewall_policy_rule (Resource)

Manages an independent rule in a [Microsoft Entra Global Secure Access cloud firewall policy](https://learn.microsoft.com/en-us/graph/api/resources/networkaccess-cloudfirewallrule?view=graph-rest-beta). Uses `/beta/networkaccess/cloudFirewallPolicies/{policy_id}/policyRules`. Creating a rule does not link its policy to traffic. Matching collections are sets: ordering and duplicates do not produce Terraform differences. Rules containing branch conditions are not currently supported.

## Microsoft Documentation

- [Microsoft Graph resource reference](https://learn.microsoft.com/en-us/graph/api/resources/networkaccess-cloudfirewallrule?view=graph-rest-beta)

## Microsoft Graph API

```http
POST   /beta/networkAccess/cloudFirewallPolicies/{policy_id}/policyRules
GET    /beta/networkAccess/cloudFirewallPolicies/{policy_id}/policyRules/{id}
PATCH  /beta/networkAccess/cloudFirewallPolicies/{policy_id}/policyRules/{id}
DELETE /beta/networkAccess/cloudFirewallPolicies/{policy_id}/policyRules/{id}
```

## Behavior Notes

- Rules are independent resources. Reference the policy resource's ID to establish Terraform creation and deletion ordering.
- Address values, ports, address groups, and protocols use sets. API order and duplicate entries do not create Terraform differences. FQDN case and CIDR host bits are preserved.
- Omitting `description` clears it; an empty string is distinct. Omitting a matching side clears that side. Destination protocols are required when the destination object is present.
- Names and priorities must be unique within a policy. To exchange priorities, move one rule to an unused priority in a separate apply first.
- Rules with nonempty branch conditions cannot currently be imported or managed; Read returns a diagnostic to avoid dropping existing conditions.
- Saving `enabled` and reading `status` does not confirm traffic enforcement. This resource does not create policy links or assignments.

## Microsoft Graph API Permissions

Application authentication requires `NetworkAccess.ReadWrite.All` for management. Read-only API calls also support `NetworkAccess.Read.All`. The tenant must have the Global Secure Access cloud firewall feature available.

## Example Usage

```terraform
resource "microsoft365_graph_beta_identity_and_access_network_cloud_firewall_policy" "example" {
  name           = "example-cloud-firewall-policy"
  description    = "Managed by Terraform"
  default_action = "allow"
}

resource "microsoft365_graph_beta_identity_and_access_network_cloud_firewall_policy_rule" "example" {
  policy_id   = microsoft365_graph_beta_identity_and_access_network_cloud_firewall_policy.example.id
  name        = "example-cloud-firewall-rule"
  description = "Match example destination addresses"
  priority    = 100
  action      = "block"
  enabled     = false

  sources = {
    addresses = [{
      type   = "ip"
      values = ["192.0.2.0/24"]
    }]
    ports = ["1024-65535"]
  }

  destinations = {
    addresses = [{
      type   = "ip"
      values = ["198.51.100.1", "198.51.100.2"]
    }]
    ports     = ["443"]
    protocols = ["tcp", "udp"]
  }
}
```

## Schema

### Required

- `action` (String) The action for matching traffic: `allow` or `block`.
- `name` (String) The rule name, unique within its parent policy. Updated in place.
- `policy_id` (String) The parent cloud firewall policy ID. Changing the parent replaces this rule, including when the new parent's ID is not yet known.
- `priority` (Number) Priority, unique within the parent policy. Lower values are evaluated first. Microsoft recommends values of at least 100; the configuration API accepts signed 32-bit values. To exchange priorities, move one rule to an unused priority in a separate apply first.

### Optional

- `description` (String) The rule description. Omitting it clears the description; an empty string is preserved.
- `destinations` (Attributes) Destination conditions. Omit this object to leave destination matching unspecified. FQDN conditions can be stored but do not work for remote-network Internet Access traffic. (see [below for nested schema](#nestedatt--destinations))
- `enabled` (Boolean) Whether the rule is enabled. Terraform defaults to false and explicitly sends disabled; the API requires a status on creation.
- `sources` (Attributes) Source conditions. Omit this object to leave source matching unspecified. (see [below for nested schema](#nestedatt--sources))
