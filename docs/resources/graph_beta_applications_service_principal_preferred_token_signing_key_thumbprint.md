# microsoft365_graph_beta_applications_service_principal_preferred_token_signing_key_thumbprint (Resource)

Manages the preferred token signing key (`preferredTokenSigningKeyThumbprint`) of a Microsoft Entra Service Principal. Setting this property activates a SAML token signing certificate for the service principal, which is required when configuring SAML-based single sign-on. Destroying this resource clears the property, returning the service principal to Microsoft Entra's automatic signing key selection; the certificate itself is not removed.

Note: Microsoft Graph does not validate that the thumbprint references an existing `keyCredential` on the service principal — ensure the thumbprint comes from a token signing certificate that exists on the same service principal.

For more information, see the [Microsoft Graph API documentation](https://learn.microsoft.com/en-us/graph/api/serviceprincipal-update?view=graph-rest-beta).

The following client `application` permissions are needed in order to use this resource:

**Required:**
- `Application.Read.All`
- `Application.ReadWrite.All`
- `Directory.Read.All`

**Optional:**
- `Application.ReadWrite.OwnedBy` (if managing only applications owned by the service principal)

Find out more about the permissions required for managing service principals at Microsoft Learn [here](https://learn.microsoft.com/en-us/graph/api/resources/serviceprincipal?view=graph-rest-beta).

## Important Notes

- **SAML Certificate Activation**: Setting this property activates a token signing certificate for SAML single sign-on. The thumbprint must reference a token signing certificate that exists on the same service principal — Microsoft Graph does not validate this.
- **Certificate Rotation**: Changing the thumbprint updates the service principal in place. Combine with `create_before_destroy` on the certificate resource for zero-downtime rotation.
- **Destroy Behavior**: Destroying this resource clears `preferredTokenSigningKeyThumbprint`, returning the service principal to Microsoft Entra's automatic signing key selection. The certificate itself is not removed.
- **Thumbprint Format**: The thumbprint is a 40-character hexadecimal SHA-1 hash without colons or spaces. Casing is compared case-insensitively and the configured casing is preserved in state.

## Example Usage

```terraform
# Complete SAML single sign-on setup with a token signing certificate
# generated by Microsoft Entra and activated via the preferred token
# signing key thumbprint.

resource "microsoft365_graph_beta_applications_application" "example" {
  display_name     = "Example SAML Application"
  sign_in_audience = "AzureADMyOrg"
}

resource "microsoft365_graph_beta_applications_service_principal" "example" {
  app_id                        = microsoft365_graph_beta_applications_application.example.app_id
  preferred_single_sign_on_mode = "saml"
  app_role_assignment_required  = true

  tags = [
    "WindowsAzureActiveDirectoryIntegratedApp",
    "WindowsAzureActiveDirectoryCustomSingleSignOnApplication",
  ]
}

resource "microsoft365_graph_beta_applications_service_principal_token_signing_certificate" "example" {
  service_principal_id = microsoft365_graph_beta_applications_service_principal.example.id
  end_date_time        = "2028-01-01T14:59:59Z"

  lifecycle {
    create_before_destroy = true
  }
}

# Activates the token signing certificate. Rotating the certificate updates
# the thumbprint reference here, which patches the service principal in place.
resource "microsoft365_graph_beta_applications_service_principal_preferred_token_signing_key_thumbprint" "example" {
  service_principal_id = microsoft365_graph_beta_applications_service_principal.example.id
  thumbprint           = microsoft365_graph_beta_applications_service_principal_token_signing_certificate.example.thumbprint
}
```
