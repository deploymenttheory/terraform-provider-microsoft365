# microsoft365_graph_beta_applications_oauth2_permission_grant (Resource)

Manages one delegated permission grant using `/oauth2PermissionGrants` on Microsoft Graph beta. A grant owns the complete set of scopes for a client service principal, resource service principal and consent identity. Import existing consent before managing it; do not manage individual scopes of the same grant in separate resources. Changing either service principal or the consent identity replaces the grant. Graph beta requires legacy creation timestamps but ignores their values; these do not provide grant-expiration controls.

## Microsoft Documentation

- [Delegated permission grant](https://learn.microsoft.com/en-us/graph/api/resources/oauth2permissiongrant?view=graph-rest-beta)
- [Create grant](https://learn.microsoft.com/en-us/graph/api/oauth2permissiongrant-post?view=graph-rest-beta)
- [Update grant](https://learn.microsoft.com/en-us/graph/api/oauth2permissiongrant-update?view=graph-rest-beta)
- [Delete grant](https://learn.microsoft.com/en-us/graph/api/oauth2permissiongrant-delete?view=graph-rest-beta)

## Microsoft Graph API Permissions

The provider requires the application permission `DelegatedPermissionGrant.ReadWrite.All` to write grants. Reading grants requires `Directory.Read.All`; `DelegatedPermissionGrant.ReadWrite.All` also permits reading them.

## Example Usage

```terraform
resource "microsoft365_graph_beta_applications_oauth2_permission_grant" "tenant_consent" {
  client_id    = "11111111-1111-4111-8111-111111111111" # Client service principal object ID
  resource_id  = "22222222-2222-4222-8222-222222222222" # API service principal object ID
  consent_type = "AllPrincipals"
  scopes       = ["User.Read"]
}

resource "microsoft365_graph_beta_applications_oauth2_permission_grant" "user_consent" {
  client_id    = "11111111-1111-4111-8111-111111111111"
  resource_id  = "22222222-2222-4222-8222-222222222222"
  consent_type = "Principal"
  principal_id = "33333333-3333-4333-8333-333333333333" # User object ID
  scopes       = ["User.Read"]
}
```

## Important Notes

- `client_id` and `resource_id` identify **service principal objects**, not application/client IDs.
- This resource owns all scopes on one grant. Import existing grants instead of creating duplicate consent, and use one Terraform resource for the complete scope set.
- `Principal` consent requires a user object ID; omit `principal_id` for `AllPrincipals`.
- Only scopes are updated in place. Changing either service principal or the consent identity replaces the grant.
- Graph beta currently requires legacy `startTime` and `expiryTime` fields during creation, although their values are ignored. The provider supplies those transport fields; this resource does not implement expiration.
- Graph directory replication can temporarily return 404 or specific 400 responses after creation or updates. The provider retries these responses within the configured timeout and confirms deletion before removing state.
