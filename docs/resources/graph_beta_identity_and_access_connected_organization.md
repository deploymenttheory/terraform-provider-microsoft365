# microsoft365_graph_beta_identity_and_access_connected_organization (Resource)

Manages entitlement management connected organizations in Microsoft Entra ID Governance using the `/identityGovernance/entitlementManagement/connectedOrganizations` endpoint. A connected organization is an external Microsoft Entra tenant or domain whose users can request access packages.

## Microsoft Documentation

- [Manage connected organizations in entitlement management](https://learn.microsoft.com/en-us/entra/id-governance/entitlement-management-organization)
- [connectedOrganization resource type](https://learn.microsoft.com/en-us/graph/api/resources/connectedorganization?view=graph-rest-beta)
- [Create connectedOrganization](https://learn.microsoft.com/en-us/graph/api/entitlementmanagement-post-connectedorganizations?view=graph-rest-beta)
- [Get connectedOrganization](https://learn.microsoft.com/en-us/graph/api/connectedorganization-get?view=graph-rest-beta)
- [Update connectedOrganization](https://learn.microsoft.com/en-us/graph/api/connectedorganization-update?view=graph-rest-beta)
- [Delete connectedOrganization](https://learn.microsoft.com/en-us/graph/api/connectedorganization-delete?view=graph-rest-beta)

## Example Usage

### Domain identity source

```terraform
# Connected organization for an external domain.
# The domain must resolve publicly and can belong to only one connected organization in the tenant.
resource "microsoft365_graph_beta_identity_and_access_connected_organization" "fabrikam" {
  display_name = "Fabrikam"
  description  = "Partner organization allowed to request access packages"
  state        = "configured"

  identity_sources = [
    {
      odata_type   = "#microsoft.graph.domainIdentitySource"
      display_name = "fabrikam.com"
      domain_name  = "fabrikam.com"
    }
  ]

  timeouts = {
    create = "180s"
    read   = "180s"
    update = "180s"
    delete = "180s"
  }
}
```

### Microsoft Entra tenant identity source

```terraform
# Connected organization for a Microsoft Entra tenant, identified by tenant ID.
# The tenant ID of a domain can be found with tenantRelationship: findTenantInformationByDomainName.
resource "microsoft365_graph_beta_identity_and_access_connected_organization" "contoso" {
  display_name = "Contoso"
  description  = "Contoso Microsoft Entra tenant"
  state        = "proposed"

  identity_sources = [
    {
      odata_type   = "#microsoft.graph.azureActiveDirectoryTenant"
      display_name = "Contoso"
      tenant_id    = "00000000-0000-0000-0000-000000000000"
    }
  ]
}
```

### External domain federation identity source

```terraform
# Connected organization for a domain federated through a SAML/WS-Fed identity provider.
# The federation must already be configured in this tenant
# (directory/federationConfigurations); otherwise Microsoft Graph returns IdentityProviderNotFound.
resource "microsoft365_graph_beta_identity_and_access_connected_organization" "woodgrove" {
  display_name = "Woodgrove"
  state        = "configured"

  identity_sources = [
    {
      odata_type   = "#microsoft.graph.externalDomainFederation"
      display_name = "Woodgrove"
      domain_name  = "woodgrovebank.com"
      issuer_uri   = "https://idp.woodgrovebank.com/saml"
    }
  ]
}
```

## Important Notes

- Connected organizations require Microsoft Entra ID Governance or Microsoft Entra ID P2 licensing.
- Microsoft Graph only accepts `identity_sources` when the connected organization is created. Changing them destroys and recreates the connected organization.
- A domain identity source must use a publicly resolvable domain, and each domain or tenant can belong to only one connected organization in the tenant.
- An external domain federation identity source requires a SAML/WS-Fed identity provider for that domain to be configured in the tenant first.
- Removing `description` from configuration clears it in Microsoft Graph.
