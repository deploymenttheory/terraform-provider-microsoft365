# microsoft365_graph_beta_identity_and_access_network_remote_network (Resource)

Manages a Microsoft Entra Global Secure Access remote network and its forwarding profile associations using the Microsoft Graph beta `/networkaccess/connectivity/remoteNetworks` endpoint. Device links and connectivity configuration are not managed by this resource.

## Microsoft Documentation

- [Remote network connectivity](https://learn.microsoft.com/en-us/entra/global-secure-access/concept-remote-network-connectivity)
- [remoteNetwork resource type](https://learn.microsoft.com/en-us/graph/api/resources/networkaccess-remotenetwork?view=graph-rest-beta)

## Microsoft Graph API Permissions

The following client `application` permissions are needed in order to use this resource:

**Required:**
- `NetworkAccess.Read.All`
- `NetworkAccess.ReadWrite.All`

## Behavior Notes

- `forwarding_profile_ids` accepts only the default Microsoft 365 and Internet Access forwarding profiles, and each must be enabled. Graph rejects a disabled profile (`Can't assign forwarding profile ... as it is disabled`) and the Private Access profile (`... is not allowed to be assigned to a remote network`). At least one profile is required.
- Associations are managed on the remote network side: changes send the full desired set to `/remoteNetworks/{id}/forwardingProfiles`. The forwarding profiles' own `associations` are never written, so associations of other remote networks are left untouched.
- Changing `region` destroys and recreates the remote network.
- Graph deletes remote networks asynchronously (about 100 seconds in testing), and the name stays reserved until the deletion finishes. Destroy therefore waits for it, so a replacement can reuse the name. `create_before_destroy` does not work unless the name also changes.
- Device links (`deviceLinks`) and connectivity configuration are not managed by this resource.
- Reads after a write are eventually consistent. Create and update wait until several consecutive reads match the configuration.

## Example Usage

```terraform
data "microsoft365_graph_beta_identity_and_access_network_forwarding_profile" "m365" {
  traffic_forwarding_type = "m365"
}

data "microsoft365_graph_beta_identity_and_access_network_forwarding_profile" "internet" {
  traffic_forwarding_type = "internet"
}

resource "microsoft365_graph_beta_identity_and_access_network_remote_network" "example" {
  name   = "example-branch-office"
  region = "eastUS"

  # Only the default Microsoft 365 and Internet Access profiles can be assigned, and they must be enabled.
  forwarding_profile_ids = [
    data.microsoft365_graph_beta_identity_and_access_network_forwarding_profile.m365.items[0].id,
    data.microsoft365_graph_beta_identity_and_access_network_forwarding_profile.internet.items[0].id,
  ]

  timeouts = {
    create = "3m"
    read   = "3m"
    update = "3m"
    delete = "3m"
  }
}
```
